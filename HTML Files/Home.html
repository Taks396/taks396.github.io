Welcome to My Site

Mission Statement

The purpose of this site is to catalog the various projects I work on over the years. This can range from cooking recipes to hobbies or stuff I've learned and will be grouped accordingly. No matter how small the project, I intend to document it so that myself or anyone who is interested can see what I have done and how it was done so that it can be replicated in the future.

Furthermore, this is not supposed to be a professional site, more like a blog. The writing here is meant to be more akin to how I talk to people (and myself honestly) rather than a robotic tutorial on how to do everything I talk about. If you don't find this useful, you are welcome to provide feedback here. There will also be a link at the bottom of every page routing you back here to provide feedback if it comes up.

Occasionally I will mention of a person I call Bijou. This is my girlfriend. She may be mentioned to provide context for the stuff I talk about or show up as an avatar in different screenshots I take. Like me, you will never know her name or see her face.

Last thing, throughout this website certain words, phrases, images and links have "hover text" attached to them. They are purposely hidden so that you can discover them, but in some cases they are more obvious because they are important for the section. This paragraph has a hidden example or two. Enjoy!

Feedback

Originally this site was hosted using GitHub Pages. I have since moved away in favor of Netlify which has allowed me to implement this feedback feature. The section works mostly how I want it to, but you will likely notice a bug where you will not be able to edit or delete your comments if you restart the browser. GitHub Pages does not allow dynamic sites. I have found a method to get around this using the Giscus application which maps comments on the site to a GitHub Disscussion in the repository. If I can ever figure out how to securely host my own site, this will become obsolete, but for the time being, it works. I am also aware that this feature requires that you have a GitHub account to leave any comments. There is nothing I can do about this until I can detach the site from GitHub Pages.

Rules:

  1. Keep things civil.

    While you might have strong opinions about a feature, I am under no obligation to add, modify, or remove content. Being respectful at least ensures your comment will be considered.

  2. Be as specific as possible.

    Generic things like "There are spelling mistakes everywhere." or "You should add content about X topic." are unhelpful. If you find a problem, tell me where to look. If you want me to add content, give me details about what you want to see. If you want a feature, give me some idea to build off of.

  3. Resolved comments will be removed.

    This isn't a forum or chat room, it's a feature I put in place to give me an outside perspective on how I can improve my site. If I agree with an idea, but haven't implemented it yet, the comment will remain. If I disagree with an idea or have added it, the comment will be removed. This is simply to reduce the feedback section clogging up the site.
